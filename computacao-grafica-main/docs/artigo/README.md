# Fontes do artigo AERIS

O documento foi compilado e conferido visualmente em **quatro páginas**, com a classe `IEEEtran` em duas colunas.

O PDF final está em `../../output/pdf/AERIS_artigo.pdf`. Os resultados apresentados correspondem à execução `resultados/execucao_20261021T030448Z_7e3fc562/`, realizada em 21/10/2026.

## Editar e compilar

Importe o arquivo `../artigo-fontes.zip` no Overleaf e escolha `main.tex` como documento principal. Outra opção é usar uma instalação TeX local com IEEEtran, babel, amsmath, booktabs, hyperref e balance. Compile duas vezes para atualizar as referências.

- `main.tex`: texto, modelagem, metodologia e referências.
- `resultados.tex`: tabela e discussão extraídas da coleta validada.
- `imagens/`: interface e gráficos utilizados no artigo.

A redação é editável. Antes da entrega, os autores devem conferir os dados institucionais e revisar o texto conforme as orientações do professor.

Ao gerar uma nova coleta, atualize a tabela, a discussão, os gráficos, a identificação do ambiente e o resumo juntos. Os valores atuais não devem ser apresentados como se pertencessem a uma máquina diferente.
